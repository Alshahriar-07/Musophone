# Musophone — Assets

This directory contains the official visual assets and branding resources for **Musophone**.

## 📁 Directory Structure

```text
assets/
├── icon.png       # Main application icon (PNG)
├── icon.ico       # Windows application icon (ICO)
├── logo.png       # Horizontal brand logo
├── banner.png     # Minimal dark promotional banner
└── README.md      # Asset documentation
```

## 🖼️ Asset Details

| File | Format | Purpose |
|---|---|---|
| `icon.png` | PNG | Primary application icon |
| `icon.ico` | ICO | Windows executable and installer icon |
| `logo.png` | PNG | Horizontal logo with icon and wordmark |
| `banner.png` | PNG | Branding, landing pages and promotional visuals |

## 🎨 Brand Identity

Musophone uses a minimal, premium, dark visual identity.

- **Primary Background:** Black / Near Black
- **Primary Foreground:** White
- **Secondary Tone:** Charcoal / Dark Gray
- **Visual Style:** Glossy, Minimal, Modern
- **Brand Symbol:** Musical note combined with an M-shaped mark and audio waveforms.

## 💻 Usage Guidelines

### Application Icon
Use `icon.png` for:
- Application interfaces
- Desktop UI branding
- Application previews

Use `icon.ico` for:
- Windows executable icon
- Windows installer icon
- Windows application shortcuts

### Logo
Use `logo.png` for:
- Application about section
- Website header
- Splash screens
- Documentation

### Banner
Use `banner.png` for:
- Landing page hero sections
- Promotional materials
- Project presentations
- Repository previews

## ⚠️ Asset Guidelines

1. Do not redesign or modify the original brand symbol.
2. Preserve the original aspect ratio when resizing.
3. Avoid stretching or distorting assets.
4. Maintain sufficient contrast against the background.
5. Prefer transparent backgrounds where supported by the asset.
6. Keep all original filenames unchanged.
