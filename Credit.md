## Original project and upstream contribution

- **Original project:** BitChord
- **Original upstream repository:** <https://github.com/kushagrasinghx/BitChord>
- **Original creator and maintainer:** Kushagra Singh
  ([@kushagrasinghx](https://github.com/kushagrasinghx))
- **Upstream revision MusoPhone is based on:** `21356206` (BitChord 1.10,
  version code 42)

MusoPhone inherits a substantial part of the original BitChord application:
its Kotlin/Java architecture, playback and media-session implementation, local
library and database code, search and catalogue integrations, Listen Together
backend and party protocol, downloads, lyrics, equalizer, addon system and the
surrounding build configuration. Those upstream-derived components were not
independently developed by MusoPhone, and this project does not claim authorship
of them.

The BitChord contributors are listed in [`MAINTAINERS.md`](MAINTAINERS.md) and
in the repository's Git history. Their copyright notices, license headers and
third-party acknowledgements remain in the source tree.

## MusoPhone modifications

MusoPhone adds its own application identity and a distinct product layer on top
of that upstream foundation. The main changes are:

- MusoPhone application name, launcher artwork, notification icon, palette and
  release identity.
- A full **Coral Glass** visual system (colours, typography, shapes, glass
  surfaces and reusable components).
- Redesigned Home, Library, Explore, Profile, Settings and player surfaces.
- A **Your Listening Experience** profile built on real on-device listening
  statistics, including top songs, artists, albums and playlists.
- Removal of the legacy BitChord launcher-icon variants and replacement with
  MusoPhone-compatible icons.
- Documentation, project links, release packaging and signing configuration for
  MusoPhone.

The complete, itemised change record is in
[`MODIFICATIONS.md`](MODIFICATIONS.md).
